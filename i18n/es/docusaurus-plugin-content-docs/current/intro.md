# Documentación de Oblikovati

**Oblikovati** es una aplicación de CAD mecánico paramétrico y basado en operaciones,
libre y de código abierto — el flujo de trabajo basado en historial que conoces de
Inventor, SolidWorks y NX, ejecutándose de forma nativa en Linux, macOS y Windows.

Traducción en curso. Las páginas aún no traducidas se muestran en inglés.
