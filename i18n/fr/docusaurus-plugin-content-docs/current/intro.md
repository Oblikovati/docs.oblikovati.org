# Documentation d'Oblikovati

**Oblikovati** est une application de CAO mécanique paramétrique et basée sur les fonctions,
libre et open source — le flux de travail basé sur l'historique que vous connaissez
d'Inventor, SolidWorks et NX, fonctionnant nativement sur Linux, macOS et Windows.
