# Keyboard Shortcuts

These are the key bindings that ship with Oblikovati, shown on an ISO keyboard and listed
by area below. Highlighted keys carry a command; hover a key to see what it does. The list
is generated directly from the application, so it always matches what the app ships.

You can rebind any of these under **Tools ▸ Customize Keyboard**. For the words you type at
the command line (AutoCAD-style, such as `REC` or `EXTRUDE`), see the
[Commands](./commands.mdx) reference.
