# Commands

Every command the command window accepts, grouped by area. Type the
**Command** — or any of its **Aliases** — at the command line and follow the prompts. The
list is generated directly from the application, so it always matches what the app ships.

Single-letter commands are not listed here; they are personalised as `Shift`/`Ctrl` chords in
the [Keyboard Shortcuts](./keyboard-shortcuts.mdx) editor.
